# Спецификация псевдоязыка шаблонов

Шаблон — это строка из **статического текста** и **токенов** в фигурных
скобках `{...}`. Статический текст переносится в новое имя как есть
(включая кириллицу); ключевые слова внутри токенов — только англоязычные
и регистронезависимые (`AND` ≡ `and`).

Три связки внутри токена:

| Связка | Назначение |
|--------|-----------|
| `=`    | задаёт формат или значение параметра |
| `AND`  | добавляет к токену ещё один параметр или модификатор |
| `OR`   | запасной вариант, если значение недоступно |

`AND` связывает сильнее, чем `OR`.

## Источники значений

| Токен | Значение |
|-------|----------|
| `{folder}` | имя текущей папки |
| `{name}` | исходное имя файла без расширения |
| `{ext}` | расширение файла (без точки) |
| `{number}` | порядковый номер файла в списке |
| `{filedate}` | дата изменения файла |
| `{photodate}` | дата съёмки из EXIF |
| `"текст"` | строковый литерал (обычно как запасной вариант после `OR`) |

## Формат через `=`

**Номер** задаётся «по образцу» первого значения — образец определяет
и стартовое значение, и ширину с ведущими нулями:

```
{number = 0001}              → 0001, 0002, 0003 …
{number = 0010 AND step = 5} → 0010, 0015, 0020 …
{number}                     → 1, 2, 3 …   (по умолчанию: старт 1, без нулей)
```

**Даты** задаются маской из плейсхолдеров `YYYY`, `YY`, `MM`, `DD`,
`hh`, `mm`, `ss` (остальные символы маски копируются как есть):

```
{photodate = YYYY-MM-DD}        → 2026-05-12
{filedate = DD.MM.YYYY_hh-mm}   → 12.05.2026_14-30
{filedate}                      → 2026-05-12   (маска по умолчанию YYYY-MM-DD)
```

Маска с пробелами берётся в кавычки: `{filedate = "YYYY MM"}`.

## Модификаторы через `AND`

| Модификатор | Действие |
|-------------|----------|
| `uppercase` | в верхний регистр (латиница и кириллица) |
| `lowercase` | в нижний регистр |
| `nospaces`  | удалить пробелы |
| `first N`   | первые N символов |
| `step = N`  | шаг нумерации (только для `{number}`, допустим отрицательный) |

```
{name AND uppercase}                → IMG_0042
{name AND lowercase AND nospaces}   → img0042
{name AND first 8}                  → первые 8 символов имени
```

## Запасные варианты через `OR`

Варианты проверяются слева направо; берётся первый, у которого есть
значение. Если значения нет ни у одного варианта — для файла фиксируется
ошибка (показывается в панели предпросмотра).

```
{photodate = YYYY.MM.DD OR filedate = YYYY.MM.DD OR "nodate"}
```

— нет EXIF → дата файла; нет и её → литерал `nodate`.

## Экранирование

Литеральные фигурные скобки удваиваются: `{{` → `{`, `}}` → `}`.

## Полные примеры

```
{folder}_{number = 0001}.{ext}
        → Vacation_0001.jpg, Vacation_0002.jpg …

Photo_{photodate = YYYYMMDD OR filedate = YYYYMMDD}_{number = 001}.{ext}
        → Photo_20260512_001.jpg

{name AND uppercase}_{number = 01}.{ext}
        → SCAN_01.pdf
```

## Грамматика

```
template  := (literal | '{{' | '}}' | token)*
token     := '{' variant (OR variant)* '}'
variant   := source ('=' format)? (AND modifier)*
           | quoted-string
source    := folder | name | ext | number | filedate | photodate
modifier  := uppercase | lowercase | nospaces
           | first ['='] integer
           | step  ['='] integer
format    := word | quoted-string
```

Ошибки парсинга содержат позицию символа в шаблоне и формулируются
в терминах языка («после OR ожидается источник или текст в кавычках»).
