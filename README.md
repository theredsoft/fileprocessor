# FileProcessor

Windows-утилита для массового переименования файлов в папке по шаблону
на простом псевдоязыке. До 10 000 файлов, многопоточная обработка,
прогресс и ETA в окне и в системном трее.

```
{folder}_{number = 0001}.{ext}                          → Vacation_0001.jpg
Photo_{photodate = YYYYMMDD OR filedate = YYYYMMDD}_{number = 001}.{ext}
{name AND uppercase}_{number = 01}.{ext}                → SCAN_01.pdf
```

## Сборка

Ядро (`fp_core`) — чистый C++20 без зависимостей, UI — Qt 6 Widgets.
Без установленного Qt собираются только ядро и тесты.

```bash
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build
```

Сборка под Windows и релизная упаковка (windeployqt + Inno Setup):
[docs/build-windows.md](docs/build-windows.md).

## Возможности

- живой двухпанельный предпросмотр: слева текущие имена, справа — будущие;
  конфликты подсвечены с причиной, кнопка «Применить» активна только
  для безопасного плана;
- проверка коллизий (дубликаты, занятые имена) и валидация Windows-имён
  (запрещённые символы, `CON`/`COM1`/…, длина);
- многопоточное переименование с прогрессом и ETA; цепочки и циклы имён
  (`a↔b`) разрешаются автоматически;
- журнал операций и «Отменить последнее переименование» — работает
  даже после перезапуска приложения;
- tray-иконка с прогрессом и уведомлениями, прогресс на кнопке таскбара;
  окно можно закрыть — работа продолжится в фоне;
- дата съёмки из EXIF (`{photodate}`) с кэшем, собственный парсер
  без внешних зависимостей;
- история шаблонов и папок, пресеты, встроенная справка по токенам.
